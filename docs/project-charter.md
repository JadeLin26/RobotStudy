# Project Charter

## 最终目标（North Star）

**双足机器人搭载摄像机，能稳定走动并完成运镜，代替摄像师完成特定镜头。**  
先在电脑仿真里证明「走得稳 + 画面可用」，再考虑真机。

详见 [final-goal.md](./final-goal.md)

## 这个项目不是什么

- 不是迪士尼 BD-X 硬件复刻
- 不是求职作品集主线（可有副产品）
- 不是第一周就电影级跟拍

## 仿真阶段「做出来」的标准

1. 原创双足机器人外形（含相机安装位/重心考虑）
2. Isaac Sim 中 **背负载（相机质量）仍能站稳、能走**
3. 虚拟相机录出 **15–60 秒** 可用片段（跟随或 A→B 建立镜头）
4. 运镜/行走参数可调（Python 或 JSON），能复现同一条 take

## 技术分工

| 模块 | 工具 | 你 / AI |
|------|------|---------|
| 造型与安装位 | Blender | **你** 定外形与相机装哪 |
| 物理与行走 | Isaac Sim 5.1 | **你** 在软件里跑；**AI** 帮脚本与排错 |
| 行走/稳定学习 | Isaac Lab（中后期） | **AI** 写环境；**你** 看画面验收 |
| 运镜逻辑 | Python + JSON | **你** 定意图；**AI** 实现 |

## 阶段路线（约 24 个月，可压缩）

| 阶段 | 焦点 |
|------|------|
| 0–1 月 | 机器人造型 + 环境 + 负载参数（相机质量/安装点） |
| 2–4 月 | Isaac 站稳、调重心、虚拟相机 |
| 5–9 月 | 行走/小步 + 画面稳定性 |
| 10–15 月 | 跟拍/路径运镜 + Isaac Lab |
| 16+ 月 | 真机或高保真 demo 可选 |

## 每周节奏

- **2–6 小时/天 × 6 天**，每周 **休 1 天**
- 时间优先：**Blender 造型** + **Isaac 看走姿/画面**；代码交给 AI 写、你跑和验收
