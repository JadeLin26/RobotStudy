# Project Charter

## 最终目标

**双足机器人，头就是相机。** 稳定走动 + 头颈运镜，代替摄像师完成特定镜头（仿真先行）。

详见 [final-goal.md](./final-goal.md)

## 设计硬规则

1. **头 = 相机本体**（镜头/传感器在头部几何内）
2. **颈 = 运镜关节**（pan/tilt，不是背上的云台）
3. **身体 = 机位移动**（走、停、转身）

## 仿真「做出来」标准

1. 原创双足造型，**头部明确是相机**
2. Isaac：头颈质量/关节合理，**负重感在头上**，能站稳、能走
3. 从**头相机**录出 15–60s 可用片段（跟拍或 A→B）
4. 运镜参数可调、可复现

## 技术分工

| 模块 | 工具 |
|------|------|
| 头相机造型 + 比例 | Blender（你） |
| 行走 + 头质量物理 | Isaac Sim |
| 走稳/跟拍学习 | Isaac Lab（中后期） |
| 运镜意图 | Python + JSON |

## 每周节奏

2–6h/天 × 6 天，休 1 天。优先 Blender 头身比例 + Isaac 走姿/画面。
