# Project Charter

## 最终目标

**1.6–2 m 双足运镜机器人：头=相机；头可升降、有限左右移、自由旋转；能走路并维持平衡。**

- [final-goal.md](./final-goal.md)
- [mechanical-spec.md](./mechanical-spec.md) ← **尺寸与关节硬指标**

## 设计硬规则

1. 站立高度 **1.6–2.0 m**
2. **头 = 相机**（非背挂）
3. 头机构：**升降 + 有限左右 + 自由旋转**（见 mechanical-spec）
4. **双足 = 行走 + 平衡**（不是纯播放动画）

## 仿真完成标准

1. 造型符合机械规格（比例尺）
2. Isaac：头机构 + 重心合理；**站得住、走得稳、头动时不易摔**
3. 头相机录出 15–60s 可用运镜片段
4. 运镜参数（含升降/横移/旋转限位）可调、可复现
