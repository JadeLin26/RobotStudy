# 机械规格（设计硬指标）

> 和 `final-goal.md` 配套；改造型前先看这一页。

## 整机

| 项 | 规格 |
|----|------|
| **站立高度** | **1.6 – 2.0 m**（地面到相机光心/头顶，可在这个区间内定一版） |
| **形态** | 双足 biped，**头 = 相机**（不是外挂背包相机） |
| **核心能力** | **走路 + 全程维持平衡**（站、走、停、转身时都不靠「假动画」糊弄） |

「维持平衡」= 腿和躯干要能在扰动、头动、地面不平时 **主动稳重心**，不是只会播走路循环。

## 头部（相机）机构 — 三层语义

```
                    [ 相机 / 镜头 ]  ← 传感器在这里
                          │
              旋转（自由转，连续）     ← 绕视轴或竖轴，构图用
                          │
              左右微移（有限行程）     ← 平行滑台，±范围 内
                          │
              高低升降（有限行程）     ← 竖直滑台
                          │
              颈基座（俯仰/偏航等）     ← 接躯干，大范围瞄准
                          │
                        躯干
                       /    \
                     腿      腿  ← 行走 + 平衡
```

| 机构 | 作用 | 仿真里要什么 |
|------|------|----------------|
| **腿 + 髋** | 机位移动、**平衡** | 接触力、重心、步态或 RL 平衡策略 |
| **颈（肩颈）** | 大范围对准目标 | 至少 pitch + yaw |
| **升降** | 高低构图（1.6–2m 内微调机位高度） |  prismatic，上下限 clamp |
| **左右微移** | 不挪脚只挪构图（斯坦尼奇式「机身平移」） |  prismatic，**有限**行程 |
| **头旋转** | 自由旋转取景 |  continuous revolute，可 360° |

具体行程数字 **第一版可先占位**（Blender 阶段用比例尺定）：

| 参数 | 建议先定（可改） |
|------|------------------|
| 升降行程 | 例如 ±15–25 cm |
| 左右行程 | 例如 ±10–15 cm |
| 整机高度范围 | 1.6–2.0 m 内由升降 + 腿站立姿态共同实现 |

## 运镜 = 身体 + 头机构 一起动

| 摄像师动作 | 机器人对应 |
|------------|------------|
| 跟着人走 | 双腿行走 + 平衡 |
| 蹲下/站高一点的构图 | **升降** |
| 横移半步不挪脚 | **左右微移**（有限） |
| 转头找角度 | **颈 + 头旋转** |

## 仿真验收（按这个规格）

1. **平衡**：扰动/头机构突然动一下，不立刻摔（可先站着测，再走）
2. **走**：直线 5m，头机构在运动中仍可微调
3. **画**：从头相机出图，升降/横移/旋转时构图变化符合预期、不抖到不可用

## Isaac 里怎么建（以后）

- 头相机 = 头 link 上的 camera sensor
- 升降 / 左右 / 旋转 = **头颈链上的关节**（prismatic + revolute），不是画在皮上的假动作
- 质量：**相机+头机构** 集中在上方，平衡难度如实反映

## 和 BD-X

可借鉴 **腿 5 DOF + 头颈多 DOF** 的思路，但你的头颈语义是 **运镜机构**（升降/横移/旋转），不是表情表演。
