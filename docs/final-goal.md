# 最终目标

## 一句话

**双足机器人 + 摄像机 = 能稳定走动的运镜平台，在仿真里先验证，以后可上真机，代替摄像师完成特定镜头。**

不是乐园表演型 BD-X 复刻；BD-X 最多是比例/可爱度的参考。

## 你要的「成片」长什么样

| 镜头类型（先做） | 说明 |
|------------------|------|
| 稳定跟随 | 机位随主体缓慢移动，画面不晃到没法用 |
| 建立镜头 | 从 A 走到 B，停住，构图成立 |
| 环绕/微调 | 小幅转向、俯仰，像摄影师在找角度 |

| 后做 | 说明 |
|------|------|
| 复杂运镜 | 甩镜、急停、低角度跟拍 |
| 真机实拍 | 仿真验证后再考虑硬件 |

## 技术本质（三块）

```
[ 双足行走 + 抗扰 ]  +  [ 机身/云台承载相机质量 ]  +  [ 运镜意图 → 路径/速度 ]
         Isaac Sim              质量/惯量/重心                 你定 + AI 实现
```

- **Blender**：机器人外形、相机安装点、大概比例（不必先追求表情表演）
- **Isaac Sim**：站着别倒、走着别栽、背上相机后还能稳
- **Isaac Lab（后期）**：学走、学稳、学跟（比「表情状态机」更贴最终目标）
- **Python**：运镜参数（跟拍距离、高度、速度上限、平滑）

## 「代替摄像师」做到什么算成功

### 仿真阶段（第一座里程碑）

- [ ] 双足代理机器人在 Isaac 里 **负重走 5–10 米** 不摔
- [ ] 虚拟相机画面 **无明显高频抖**（能当 B-roll 背景）
- [ ] 一条可重复的「跟拍」demo：目标点移动，机位跟着走

### 以后（真机）

- 真双足 + 云台/减震 + 图传
- 仍建议：**仿真里走通的 gait 和重心策略** 再上车

## 风险（直说）

- **比「站着做表情」难一档**：行走 + 相机质量 = 典型 locomotion + manipulation 问题
- **策略**：先 **负重站立 + 小步/原地调整**，再 **直线走**，再 **跟拍**；不要第一周就追求电影级运镜
