# 最终目标

## 一句话

**双足机器人，头就是相机**——整机是一台能稳定走动的「摄像师」，不是身上再背一台相机。

先在仿真里验证：走得稳 + 头（相机）画面可用，能完成特定运镜。

## 结构概念（重要）

```
        [ 镜头 / 传感器 ]  ← 这就是「头」，不是装饰品
              │
         颈（俯仰/偏航）   ← 运镜 = 头颈 DOF + 身体移动
              │
           躯干
          /    \
        腿      腿
```

- **没有**「背上云台再挂相机」——头即机位
- 身体走动 = 机位平移；头颈 = 构图微调（pan/tilt）
- 设计时要考虑：**头偏重**、重心偏高（像摄像师举着机器走）

## 你要的「成片」

| 先做 | 说明 |
|------|------|
| 稳定跟随 | 身体跟着主体走，头对准，画面不晃到没法用 |
| 建立镜头 | 从 A 走到 B，头保持构图，停住成立 |
| 小幅找角度 | 颈关节微调，像摄影师扭头找机位 |

## 技术三块

| 块 | 内容 |
|----|------|
| 行走 | 双足 + 抗扰，头质量算进物理 |
| 头颈运镜 | 头=相机 sensor；颈 DOF =  cinematography |
| 意图 | 跟拍距离、高度、速度、lookahead — Python/JSON |

## 仿真里程碑

- [ ] **M1** Blender：造型，**头是相机外形**（镜头筒/方块 sensor 即可）
- [ ] **M2** Isaac：头质量 + 颈关节，**站着**虚拟画面稳
- [ ] **M3** Isaac：走直线不摔（头质量在动力学里）
- [ ] **M4** 跟拍 demo：身动 + 头对准，15–60s 可用

## 和 BD-X

BD-X 也是「头颈有表达」——你可以借鉴 **头颈 4 DOF** 思路，但语义改成 **运镜**，不是卖萌表情。

## 风险

头重 + 双足走 = 比轻头难；先站稳再快走。
