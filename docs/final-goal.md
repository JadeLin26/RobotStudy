# 最终目标

## 一句话

**高约 1.6–2 m 的双足机器人：头就是相机，带升降 / 有限左右移动 / 自由旋转；能走路并持续维持平衡，代替摄像师完成特定运镜。**

## 尺寸与机构（摘要）

| 项 | 要求 |
|----|------|
| 身高 | **1.6 – 2.0 m**（站立） |
| 头 | **相机本体**（不是背挂） |
| 头机构 | **高低升降** + **一定范围左右移动** + **自由旋转** |
| 腿 | **行走 + 维持平衡**（站走停转都要稳） |

完整关节与行程见 **[mechanical-spec.md](./mechanical-spec.md)**。

## 结构示意

```
[ 相机 ] — 旋转（自由）
    |
  左右滑台（有限）
    |
  升降滑台
    |
  颈（俯仰/偏航）
    |
  躯干 — 平衡
 /    \
腿    腿 — 行走
```

## 里程碑

- **M1** Blender：1.6–2m 比例 + 头=相机 + 标出升降/左右/旋转机构（可先示意）
- **M2** Isaac：头机构质量 + **站立平衡** + 虚拟画面稳
- **M3** Isaac：**走着不摔** + 头动不立刻倒
- **M4** 跟拍：身动 + 头机构运镜，15–60s 可用

## 技术栈

Blender 定型 → Isaac Sim 物理与平衡 → Isaac Lab 行走/平衡/跟拍（后期）→ Python 运镜参数。

详见 charter、mechanical-spec、todolist。
